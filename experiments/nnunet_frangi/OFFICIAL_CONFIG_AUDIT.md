# 官方配置核对与本轮执行决定

核对日期：2026-11-08。来源：
- https://github.com/kitbransby/ImageCAS-X
- https://raw.githubusercontent.com/kitbransby/ImageCAS-X/main/configs/nnunet.json
- https://arxiv.org/html/2608.30404v1 （附录 E、F）

官网 nnunet.json 仅声明方法名，未提供可复现的 plans/trainer 参数。本次网页核对未取得固定 commit，不能声称严格复现。

| 项目 | 官方公开设置 | 本地设置/决定 |
|---|---|---|
| 优化器/损失 | SGD，Dice+CE，深监督，batch 2，初始 LR 0.01 | 保留现有配置；低 LR 实验只改变收敛策略 |
| 训练预算 | 每轮250训练/50验证批次；多项式衰减0.9；实际总轮数仍待核实 | 基线245轮；独立续训最多200轮，起始LR0.001，patience80 |
| 输入 | 0.5mm各向同性；[-200,1000] HU映射至[0,1] | 当前CT+Frangi自动规划与CT归一化；不混改为官方预处理 |
| 采样 | 至少50%批次含前景 | nnU-Net默认0.33，batch2的确定性取整实际为1/2前景 |
| 增强 | 冠状/矢状翻转，无旋转和轴向翻转 | 原生nnU-Net增强；本轮保持不变，属于已知差异 |
| TTA | 两个平面轴的四种组合 | 本地nnU-Net训练记录的轴；不可称为相同TTA |
| 后处理 | 原始分辨率上移除小于100体素的连通域 | 本地100mm³实验与100体素不同；不直接设为默认 |
| 评分 | 验证选模，统一全体积评估 | 先补齐四组基线验证；保留测试暂不评估 |

决定：先完成基线验证，再执行原计划中的低学习率对照，以检验提前早停假设。预处理、增强、输入通道等差异留待独立对照，不在本轮同时改变。权重配套plans、确切trainer版本和官方总训练预算仍未知，不能把本轮结果描述为论文复现。

执行入口已改为默认只验证；只有显式传入 finish_experiment.py --evaluate-holdout 才会运行保留测试，须在整个优化方案冻结后使用。
