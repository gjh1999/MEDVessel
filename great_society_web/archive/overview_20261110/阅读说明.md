# 网页报告阅读说明

双击 index.html 即可离线阅读。请保留 photos 文件夹；data.json 是图表数据，photos.json 是图片原始作者、许可、年代和来源记录。

内容含12节正文、5幅统计图、4幅机制图、1张制度比较表和可展开双轨时间线。另有7张历史/生活照片及1张1973年车票实物图；车票没有被标作生活照片。部分档案时间元数据与文件名不一致，正文图注已明确，不作为年代论据。

养老统计采用2024年度国家老龄事业发展公报的正式数据（职工53452万人、居民53830万人），不混用早期快报的职工53449万人。人口普查2010值按2020公报的十年百分点变化还原，已在图旁说明。

验证：已检查全部本地图片、内部目录锚点及图表数据输出。页面采用响应式布局与原生details交互，不依赖CDN。浏览器访问host不可用，原生Chrome审批等待超时，未完成真实浏览器视觉验证；不声称已通过桌面/手机截图检查。未安装新的大型浏览器依赖。

阅读边界：统计选取已核查的历史节点及2023/2024截面，未伪造连续年度数据；中国2020年代仍在变化。报告是历史制度比较，不是跨国福利排名，也不提供政策净效果的因果估计。
