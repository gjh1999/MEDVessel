Project summary

01 项目定位与目标

开发一套面向三维 CT 血管造影（CTA）的传统医学图像处理系统。输入 DICOM 序列或 NIfTI 体数据，输出血管增强响应图、血管分割 Mask、中心线图结构，以及血管长度、局部直径、截面积、分支角度和曲率等几何信息。

算法深度

自行实现 Hessian、对称矩阵特征值分解、Frangi、区域生长、距离变换和骨架图分析。

医学影像工程

正确处理体素间距、图像方向、物理坐标、DICOM 元数据和三维内存布局。

工程可验证

提供单元测试、合成数据、公开数据集实验、性能基准和可复现参数。

项目定位：研究型工程 Demo，用于展示传统医学影像算法与 C++ 工程能力，不是临床诊断产品，不用于患者诊断或治疗决策。

Problem definition

02 项目要解决的实际问题

血管在 CTA 中表现为三维管状结构，但实际图像中存在噪声、灰度不均、血管粗细变化、弯曲和分叉。骨骼、钙化、静脉及邻近增强组织也可能产生相似高灰度响应。因此，简单阈值无法稳定地区分血管与背景。

血管增强

利用局部二阶结构和多尺度分析，突出细长管状结构，降低片状结构与平坦背景响应。

血管分割

结合血管增强响应、用户种子、区域生长和连通性约束，提取目标血管区域。

中心线与拓扑

从三维 Mask 提取中心线，识别端点、分叉点和分支关系，尽量保持真实连通结构。

几何定量

基于患者物理坐标计算血管长度、直径、截面积、分支角度与曲率。

范围控制：第一版只选择一种 CTA 场景，例如冠状动脉 CTA 或脑血管 CTA。不要一开始同时覆盖冠脉、脑血管、肺血管和 MRA。

Medical image fundamentals

04 三维数据结构与医学物理坐标

医学影像不是普通二维图片。每个体素除了数组索引，还对应患者空间中的物理位置。长度、直径、角度和曲率必须在物理坐标中计算，不能直接把 voxel index 当作毫米。

Pworld = Origin + Direction × (Index ⊙ Spacing)

Index = (i,j,k)，Spacing = (sₓ,sᵧ,sz)，Direction 为 3×3 方向矩阵，⊙ 表示逐元素乘法。

Volume3D 基础结构

template<typename T>
struct Volume3D {
    int width, height, depth;
    std::array<double, 3> spacing;
    std::array<double, 3> origin;
    std::array<double, 9> direction;
    std::vector<T> data;

    // 示例连续内存布局：
    // index = (z * height + y) * width + x
};

DICOM / NIfTI 读取注意事项

  • 使用 DCMTK 或 GDCM 负责 DICOM 解析，不从零实现完整 DICOM 标准。
  • DICOM 切片不能仅按文件名排序；应结合 ImagePositionPatient 与 ImageOrientationPatient 计算切片法向量并排序。
  • 读取 Pixel Spacing、Slice Spacing、Image Orientation、Image Position 等元数据。
  • CT 像素值结合 Rescale Slope 和 Rescale Intercept 转换为 HU，并处理异常序列。
  • 明确患者坐标系、数组轴顺序和左右/前后/头脚方向，禁止静默翻转数据。
开发建议：先支持 NIfTI 输入，验证 Volume3D 和 Geometry；再增加 DICOM Series Reader，把格式解析与算法开发分离。

各向异性体素

CT 的层间距和面内像素间距往往不同。Gaussian sigma、距离变换、长度、直径和曲率必须考虑 spacing。可以在物理空间使用各向异性卷积，也可以在明确记录插值方法后重采样到近似各向同性网格。

Core algorithm 01

05 三维 Hessian 与多尺度 Frangi 血管增强

最高优先级核心算法自行实现

目标：利用局部二阶结构判断体素邻域是否呈管状形态，增强 CTA 中的血管，抑制平坦背景、片状结构和部分噪声。

5.1 三维 Hessian 矩阵

H(I) = [ Ixx Ixy Ixz ; Iyx Iyy Iyz ; Izx Izy Izz ]

Hessian 对称，只需计算六个独立分量。使用 Gaussian 的一阶/二阶导数核与输入体数据卷积，建议使用可分离卷积降低计算量。导数计算考虑物理 spacing；多尺度时明确是否使用 σ²·H 做尺度归一化。

5.2 Jacobi 3×3 对称矩阵特征值分解

自行实现 Jacobi Eigenvalue Algorithm：寻找最大非对角元素、构造平面旋转、执行相似变换、检查收敛、提取特征值和特征向量。特征值排序时必须同步调整特征向量。

struct EigenResult3x3 {
    std::array<double, 3> values;
    // vectors[i] 必须与 values[i] 对应
    std::array<std::array<double, 3>, 3> vectors;
};

EigenResult3x3 jacobiEigenDecomposition(
    const SymmetricMatrix3x3& hessian
);

按绝对值排序：|λ₁| ≤ |λ₂| ≤ |λ₃|。理想亮管状结构通常满足 |λ₁| 较小、λ₂ 和 λ₃ 为负。实际符号依赖导数定义与灰度极性，必须用合成亮管/暗管 Phantom 验证。

5.3 Frangi Vesselness

RA = |λ₂| / (|λ₃| + ε)
RB = |λ₁| / (√(|λ₂λ₃|) + ε)
S = √(λ₁² + λ₂² + λ₃²)
V = (1 − exp(−RA² / 2α²)) · exp(−RB² / 2β²) · (1 − exp(−S² / 2c²))

亮血管模式需按特征值符号筛选；暗血管模式切换符号规则。分母加 epsilon 防止数值异常。α、β、c 可配置，c 可根据数据统计量设定，不能认为一组固定参数适用于所有扫描。

5.4 多尺度融合

V(x) = maxσ ∈ Σ Vσ(x)，同时保存 BestScale(x)

sigma 列表表示目标血管尺度，建议以毫米表达，再根据 spacing 转换为各轴 voxel sigma。每个尺度计算 Hessian、特征值和 Frangi 响应，最终取最大响应并保存对应尺度。

5.5 本模块交付清单

  • Gaussian、Gaussian 一阶导数和二阶导数核生成
  • 3D separable convolution 与明确的边界策略
  • Hessian 六个分量计算
  • Jacobi 特征值和特征向量分解
  • 特征值绝对值排序、亮/暗管符号判断
  • Frangi 响应、多尺度 max、BestScale
  • 合成 Phantom 单元测试和数值稳定性测试
关键算法细节：血管切向通常对应最小绝对值特征值的特征向量。ridge 的 NMS 应沿横截面法向方向比较响应，而不是沿血管切向直接抑制。3D NMS 可在两个横截面主方向采样，并用三线性插值处理非整数坐标。
Core algorithm 02

06 三维血管分割

Frangi 输出连续 vesselness response，不是最终二值分割。第一版采用“用户种子 + vesselness 双阈值 + 区域生长”的可解释方案，后续再扩展 Level Set / Fast Marching。

6.1 3D Non-Maximum Suppression

利用 Hessian 特征向量确定局部血管切向与横截面方向，在横截面法向方向比较响应，抑制血管周围的非中心响应。三维横截面有两个方向，可沿两个法向分别采样；采样点通常不是整数体素，需要三线性插值。

6.2 Seeded Region Growing

Seed(p) = [V(p) ≥ Thigh]
Grow(q) = [V(q) ≥ Tlow] ∧ [IntensityConstraint(q)]
  • 高阈值确定可靠种子，低阈值允许向相邻体素扩张。
  • 采用 26 邻域或可配置邻域，队列使用 BFS。
  • 使用 visited 标记避免重复入队。
  • 可增加灰度范围、ROI、方向连续性或最大跳变约束，减少向骨骼/背景泄漏。
  • 阈值和约束参数必须配置化并记录实验结果。

6.3 3D Connected Components

实现 3D 连通域标记，支持 6/18/26 邻接配置，统计组件体素数、物理体积、包围盒和与种子点的关系。不能简单删除所有小组件，因为真实细小血管分支也可能很小。

6.4 后续扩展：Fast Marching / Level Set

Level Set 用隐式函数 φ(x,y,z,t)=0 表示边界，典型演化形式为 ∂φ/∂t + F|∇φ|=0。后续需研究 upwind finite differences、曲率项、时间步长/CFL 稳定性和重初始化。此部分不属于第一版 MVP。

Core algorithm 03

07 距离变换、三维骨架与中心线图

目标：从血管 Mask 中提取近似单体素宽的中心线，并将骨架压缩成可分析的血管分支图。

7.1 Euclidean Distance Transform

D(p) = minq ∉ Mask √[(Δx·sₓ)² + (Δy·sᵧ)² + (Δz·sz)²]

距离必须考虑各向异性 spacing。建议研究可分离的精确欧氏距离变换算法，而不是对每个前景体素暴力搜索最近背景点。距离场可辅助估计局部半径。

7.2 Topology-preserving 3D Thinning

研究 Lee 等人的 3D 细化方法或其他拓扑保持 thinning。关键不是不断删除边界体素，而是判断候选体素是否为 simple point，删除后不能破坏对象连通性或改变不希望改变的拓扑结构。需要明确前景/背景邻接约定并测试。

7.3 Skeleton 转换为 Graph

G = (V,E)，V 表示端点/分叉节点，E 表示节点之间的骨架路径
骨架体素邻居数初步分类处理说明
1端点通常是血管末端，需排查噪声短枝
2路径点压缩进相邻节点之间的 Edge
≥3潜在分叉点相邻分叉体素聚类成一个节点，不能逐体素认作多个分叉
struct VesselNode {
    Point3D positionWorld;
    std::vector<int> adjacentBranches;
};

struct VesselBranch {
    int startNodeId;
    int endNodeId;
    std::vector<Point3D> centerlineWorld;
    double lengthMm;
    double meanRadiusMm;
};

需要处理短枝修剪、环路、断裂、交叉和分叉点聚类。不能只凭 26 邻域度数大于等于 3 就认定为真实分叉。

Core algorithm 04

08 血管几何与定量分析

8.1 直径与截面积

快速近似：在中心线位置读取 EDT 半径 r≈D(p)，直径 d≈2r。该近似受中心线偏移、非圆形截面和分割误差影响，不能当作精确临床测量。

更稳健的方式：估计中心线切向量，构建垂直于切向量的局部截面平面，将原始图像/Mask 重采样到平面，计算截面积 A，并给出等效直径：

deq = 2√(A / π)

8.2 长度、分支角度和曲率

L = Σi ||pi+1 − pi||world
θ = arccos((u · v) / (||u|| ||v||))
κ = ||r′(t) × r″(t)|| / ||r′(t)||³

所有几何计算均使用物理坐标。曲率对噪声敏感，先对中心线做有明确参数的平滑，再计算导数。分支角度应在分叉点附近拟合父/子分支的局部方向，而不是只取紧邻分叉点的单个向量。

8.3 输出报告字段

字段单位/类型说明

lengthmm中心线弧长
mean / min / max diametermm沿分支的直径统计
cross_section_areamm²指定采样位置的截面积

Development principles

14 实施原则与风险控制

  • 先正确、后优化：先建立小体积、单线程、可重复的正确性基线，再考虑 OpenMP 和内存优化。
  • 每个算法都有测试：矩阵特征值、导数卷积、Frangi 符号、距离变换、骨架拓扑都需要独立测试。
  • 区分参考实现和最终实现：可以使用 ITK/VTK/OpenCV 做独立对照，但核心处理路径不能调用它们的同类现成算法。
  • 保留失败案例：记录骨骼干扰、钙化、血管粘连、细分支断裂、噪声泄漏等情况，说明当前方法的边界。
  • 避免过度扩张：第一版不强求 GUI、GPU、Level Set 和所有 DICOM 厂商兼容；先完成算法核心闭环。
推荐的第一条开发链路：Volume3D → Gaussian Derivative → Hessian → Jacobi Eigen Solver → Frangi。先把这条链路独立实现、测试和跑通，再进入分割与中心线阶段。
