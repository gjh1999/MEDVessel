# 验证记录与验收范围

记录日期：2026-11-02。主流程已完成端到端运行，以下区分“功能跑通”与“泛化准确性验证”。

## 环境与测试

本机：Windows、MSYS2 UCRT64 GCC 16.1、C++17、Ninja Release、CMake 4.4.4。
启用 NIfTI-1 I/O、zlib、DCMTK 3.6.9、GoogleTest 1.17.0、可选 OpenMP。
当前完整构建（含 Qt 6.11.1）的 **27 个 CTest 项全部通过**；原算法/格式/下载器 26 项，加 GUI 集成 1 项。下载器项还包含 2 个 Python unittest。
GUI 集成包含 8 项行为检查及初始化/清理：ROI 换算、配置往返、真实 CLI 与窗口结果读回、缺失输入、中文路径、无效影像、中止/独立目录、启动失败；Qt 明细在 build/cmake/gui-test-results.txt。
测试数依启用的依赖变化；此前无格式库/框架的核心构建也验证通过，不能机械要求所有配置都有 27 项。GUI 使用 offscreen 自动测试，尚无多 DPI/多系统交互验收。

```powershell
& ./.venv/Scripts/cmake.exe --build build/cmake --parallel 4
& ./.venv/Scripts/ctest.exe --test-dir build/cmake --output-on-failure
```

| 数据获取 | 选中成员 CRC、SHA 缓存、损坏不提交、离线测试 | 不把网络稳定性纳入单元测试 |

## 合成结果

| 场景 | 当前 Dice | 分支图检查 |
| --- | --- | --- |
| 直圆柱 | 0.957447 | 1 条，长度 16 mm |
| 弯曲管 | 0.862807 | 1 条 |
| Y 型 | 0.883053 | 3 条 |
| 带噪斜管 | 0.920570 | 1 条 |

直圆柱参考直径为 4 mm：EDT 平均直径约 3 mm、截面等效直径约 3.785 mm。
这直接说明不同估计和离散边界存在偏差，不能以“函数有输出”作为测量准确性的证明。
斜向折线长度受栅格锯齿影响，圆帽/分割端点也会影响长度。

曾出现 Y 型/弯曲管多余分支，改为全局 EDT 优先队列顺序删除后加入回归检查；没有直接并行删除 simple point。

## 性能记录

80×80×48、两尺度 Frangi 的一次本机测量：1 线程约 0.426 s，4 线程约 0.230 s。
响应图和最佳尺度图逐体素最大差异均为 0；加速只涉及卷积。
冠脉开发 ROI 的运行时间约数秒至十秒，受机器负载和 I/O 影响，不作为稳定吞吐量指标。
目前未完成多次重复统计、峰值内存、完整 CTA、CPU/编译器组合的系统性能基准。
