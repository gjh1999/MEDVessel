# 开发进度

以 [网页方案](medical_vessel_analysis_project.html) 为开发依据。

## 已落地的算法基线

| 阶段 | 实现 | 尚缺内容 |
| --- | --- | --- |
| 1：影像基础 | Volume3D、物理坐标、Gaussian、线性/最近邻重采样、ROI、NIfTI-1、经典 DICOM CT 读取 | 真实厂商序列验证、压缩/增强 CT 支持 |
| 2：局部结构 | Gaussian 导数、六分量 Hessian、Jacobi 特征值与向量 | 与独立实现对照 |
| 3：增强 | 多尺度 Frangi、BestScale、亮/暗管模式、单病例开发样例与对照图 | 独立多病例的尺度/参数和响应稳定性验证 |
| 4：分割 | NMS 种子、区域生长、双阈值传播、灰度约束、连通域过滤、Dice/HD95/clDice/中心线距离 | 真实冠脉鲁棒性与独立评估 |
| 5：中心线与几何 | 精确 EDT、距离优先 simple-point 细化、分叉聚类、闭环、短枝修剪、长度、截面、角度与曲率报告 | 复杂数据的骨架稳定性、亚体素精度 |
| 6：性能与可视化 | 可选 OpenMP、单/四线程一致性基准、SVG/PNG、Qt 6 桌面工作台（参数、异步任务、投影与分支表） | 内存与大体积基准、三方向切片交互与 VTK 三维显示 |

已有可运行的 NIfTI CLI 和合成数据生成程序。CLI 导出增强、尺度、Mask、骨架、半径场、分支表、中心线坐标及运行参数。
支持命令行配置尺度、Frangi 参数、阈值、强度范围、连通性与重复种子。

## 已知限制

- 细化是顺序拓扑保持侵蚀基线，采用前景 26 / 背景 6 邻接；不是 Lee 算法，复杂输入可能残留片状骨架或毛刺。
- 图压缩使用 26 邻域度数，相邻高阶点聚类；密集邻接可能合并真实分叉。
- 分支长度未补偿分叉簇内部长度；图未指定根，不推测父子关系。
- EDT 搜索体积内背景，全前景返回无穷；CLI 此时跳过半径场导出，直径留空。
- NIfTI 保留 RAS 毫米坐标，sform 优先；未知单位、无变换和剪切网格显式拒绝。
- 分割种子使用体素索引；现有三线性重采样仅用于连续灰度。
- DICOM 当前限定单帧、未压缩、16-bit MONOCHROME2 经典 CT；显式拒绝混合序列、重复/不均匀位置及倾斜网格。
- VMTK 示例的参考结果不是完整人工金标准；冠脉目前仅验证一个参考辅助局部开发案例，尚无独立多病例评估，未宣称全计划完成。
